# Web Studio

Демонстраційний проєкт для презентації портфоліо: статичний адаптивний сайт вебстудії з інформацією про послуги, команду та прикладами робіт.

## Можливості

- адаптивна навігація для мобільних пристроїв;
- головний екран із кнопкою замовлення послуги;
- модальне вікно з контактною формою;
- блоки з перевагами студії, командою та прикладами робіт;
- посилання на контакти й соціальні мережі.

> Форма замовлення демонстраційна: після натискання «Send» вікно закривається, але дані не зберігаються та не надсилаються на сервер.

## Запуск

Проєкт не потребує встановлення залежностей або збірки.

1. Завантажте або клонуйте репозиторій.
2. Відкрийте `index.html` у браузері.

Для локальної розробки можна відкрити папку проєкту у Visual Studio Code та скористатися розширенням Live Server.

## Структура проєкту

```text
.
├── index.html       # Розмітка сторінки
├── index.css        # Стилі та адаптивна верстка
├── script.js        # Поведінка меню й модального вікна
└── images/          # Ілюстрації, іконки та фотографії
```

## Технології

- HTML
- CSS
- JavaScript без сторонніх бібліотек
